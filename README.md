## 30 秒速览

- **赛事**：第四届，教育部+重庆市人民政府主办，2026年10月—2027年4月，校赛→省赛→国赛三级，平台 `zgs.chsi.com.cn`
- **赛道**：成长赛道（本专科非毕业年级，7′陈述+5′提问+2′实习offer，材料2份）；就业赛道（高年级求职生+研究生，6′陈述+6′面试+2′天降offer，材料3份）
- **评分（关键，本届有变）**
  - 成长赛道：职业目标 **25** ＋ 学习实践行动 **50** ＋ 优化改进 **25**（第三届为 30/50/20，权重已变）
  - 就业赛道：职业目标 **10** ＋ 岗位胜任力 **80**（综合素质40＋专业能力40）＋ 发展潜力 **10**
- **时间**：报名最晚 2027-01-31（各校自定，多数 11 月收材料）；省赛须 2027-03-15 前完成；总决赛 2027年4月（重庆）
- **名额**：国赛约 800 人（成长约450 / 就业约350），**每校各组别≤1 人**

## 最要紧的三件事

1. **先找本校通知**——真正的截止日是学校定的，通知里的 1 月 31 日只是兜底线。
2. **目标职业/目标行业早定**——决定国赛赛场分组，晋级后不得修改。
3. **别用往届口径**——本届成长赛道评分权重已改，网上大量 30/50/20 的资料已经过时。

## 可信度声明

分值与材料要求来自多所高校对教育部附件1/2 的逐字转载互证（青岛黄海学院、上海师范大学天华学院、长春职业技术大学、华南师范大学等），并与通知正文交叉核对。因整理环境无法解析 .docx 附件，以下细节建议以官方原文或本校通知最后核对：

- 评分表一级指标的确切名称（"学习实践行动" vs "成长行动"）
- 是否允许 PPT 内嵌视频（第三届明确允许，第四届转载文本未见该表述）
- 辅助证明材料上限（官方附件为 10MB，部分学校通知误写 50MB）
- 第四届是否仍设"课程教学赛道"（本届通知主体赛事仅列成长/就业两个赛道）
